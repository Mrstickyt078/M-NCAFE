# M&N Café

Material de la marca M&N Café: página web y comerciales de 30 segundos.

## Contenido

- `web/` — página web lista para subir a un hosting. `index.html` es la página principal.
- `MN_Cafe_Comercial_30s.mp4` — comercial del producto (16:9).
- `MN_Cafe_Dos_Mananas_30s.mp4` — comercial «Dos mañanas, un mismo café» (16:9).
- `MN_Cafe_Dos_Mananas_30s_vertical.mp4` — el mismo comercial en vertical (9:16) para redes.
- `guion_tomas_dos_mananas.md` — guion de tomas con prompts para generar el comercial con IA de video.

## Créditos

Los clips de video y la música de los comerciales son de Mixkit (licencia gratuita de Mixkit).
